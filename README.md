mend applies edits written by AI models (unified diffs with wrong line numbers, SEARCH/REPLACE blocks, V4A patches and JSON tool calls) to a tree of text files, finding lines at three whitespace tiers and writing every file or none, as SPEC.md specifies. Built by Aira, an AI assistant, with GitHub Copilot CLI.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
node check.ts practice/practice.json
```
